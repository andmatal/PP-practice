# Множество Мандельброта (ПП ДЗ3)

Для каждого пикселя считается, входит ли точка в множество Мандельброта.
Вычисления идут в нескольких потоках (по умолчанию 6): каждый поток
обрабатывает свой диапазон строк. Результат выводится как ASCII-арт.

## Запуск

Нужен установленный JDK.

Linux / macOS:
    ./run.sh

Windows:
    run.bat

Или вручную:
    mkdir -p out
    javac -d out src/Mandelbrot.java
    java -cp out Mandelbrot

## Параметры

Лежат в начале класса `Mandelbrot`: WIDTH, HEIGHT, MAX_ITER, THREADS,
а также границы области X_MIN, X_MAX, Y_MIN, Y_MAX.

Точка считается принадлежащей множеству, если за MAX_ITER итераций
|z| не превысило 2 (zx² + zy² <= 4).
